Support and security

Last updated 2026-11-16

Get help

Write to chris@attainable.ai. A useful report names the tool you called, the arguments you sent, and the dataset block from the response. Setup steps and common fixes are on Connect your agent.

Dispute a score

Every record carries the policy quote and the source URL its score rests on. If an institution's policy has changed, or a score reads the source wrongly, send the source and the passage. The methodology explains how each dimension is coded.

Report a security problem

Email chris@attainable.ai with SECURITY in the subject line. Please report privately and allow time for a fix before you publish. Include the URL, the request you sent, and what happened. Good-faith research on this site and its endpoint is welcome. Please do not degrade the service for others.
