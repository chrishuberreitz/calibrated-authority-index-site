Privacy

Last updated 2026-11-16

The short version. The Index is public data. The agent endpoint needs no account and sets no cookies. It records which tool was called and whether the call worked. It does not record what you asked.

The agent endpoint

This covers /api/mcp, the hosted MCP endpoint described on Connect your agent.

  • What it receives. The request your agent sends: a tool name and its arguments, such as an institution name or a filter. The endpoint uses them to compute the answer and then discards them.
  • What it records. One log line per tool call, holding the tool name and the outcome (ok, error, unknown tool, or exception). Nothing else.
  • What it does not record. The arguments you sent, any text from your conversation, your name, your account, or which agent or client made the call.
  • What it never asks for. Conversation content, credentials, or personal data. The tools read a published dataset and need none of these.

The endpoint has no sign-in, so it has no way to know who is calling.

The web pages

The Index pages use Google Analytics, which sets cookies, and Vercel Web Analytics, which does not. Both count visits in aggregate. This page and the support page load neither.

Who processes it

  • Vercel hosts the site and the endpoint. Like any host, it handles the network details a web request carries, including IP address and user agent, to deliver and protect the service. It holds the log lines above. See Vercel's privacy policy.
  • Google processes the analytics data for the web pages. See Google's privacy policy.

How I use it

  • To count how often each tool is used.
  • To find and fix errors.
  • Nothing else. No selling, no sharing for marketing, no advertising, and no profiles of the people or agents who call the endpoint.

How long it is kept

The log lines live in Vercel's logs for the limited period Vercel keeps them. I keep no separate copy. Analytics data is held by Google and Vercel under their own retention terms.

If this changes

If the endpoint ever records more than the tool name and the outcome, this page will say so before the change goes live.

Questions and requests

Write to chris@attainable.ai to ask what is held or to request deletion. The Calibrated Authority Index is published by Chris Huber Reitz.
